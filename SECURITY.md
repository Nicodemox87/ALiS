# Security and privacy

Report suspected security vulnerabilities privately to **nicodemo.abate@cnr.it** before posting exploit details publicly. Include the version, affected component and a minimal safe reproduction. No guaranteed response time is currently offered for this research alpha.

Load only trusted model/catalogue files. Joblib/pickle deserialisation can execute code. Do not distribute models from untrusted sources as validated assets. Download installers only from this repository and verify published hashes. The alpha installer is unsigned; hashes verify integrity against this publication, not independent publisher identity.

Do not upload restricted archaeological surveys, personal information, credentials, local paths or unpublished research in issue reports. Public example data must have explicit redistribution permission. This release contains no training dataset or pretrained model.
