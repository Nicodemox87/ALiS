# macOS — work in progress

Native Apple Silicon support for ALiS is under development. There is currently no validated macOS build or Mac installer available for download.

The published Windows alpha.5.7 release remains unchanged. Mac installation instructions and downloads will be published after native build, functional, installation and interactive validation. No release date is committed.

This page is a status announcement, not an installation guide. Development handoff material is maintained separately while the port is in progress.
