# Historical backup packages

The binaries and VERSION.json in this directory belong to the historical **Windows alpha.5.7** snapshot.

For **Windows/macOS alpha.5.9**, including progressive features and update checks, use the [current release](https://github.com/Nicodemox87/ALiS/releases/tag/v0.1.0-alpha.5.9). The complete Windows installer prepares CloudCompare, ALiS and the Python ML/DL runtime; plugin-only setup and manual ZIP are alternatives. The native arm64 Mac installer is a separate PKG.

Verify downloads against the checksum files attached to the **same release**. [Installation instructions](../docs/WINDOWS_COMPLETE_INSTALLER.md) · [Fixes and limitations](../docs/RELEASE_ALPHA59.md).

The previous Mac installer remains available under [alpha.5.7](https://github.com/Nicodemox87/ALiS/releases/tag/v0.1.0-alpha.5.7). Windows packages cannot update the Mac app.
