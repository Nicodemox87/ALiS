# Historical backup packages

The binaries and VERSION.json in this directory belong to the historical **Windows alpha.5.7** snapshot.

For **Windows alpha.5.8**, including Annotation Studio corrections and geometric-feature memory protections, use the [current release](https://github.com/Nicodemox87/ALiS/releases/tag/v0.1.0-alpha.5.8). Its complete installer prepares CloudCompare, ALiS and the Python ML/DL runtime; the plugin-only installer and manual ZIP are alternatives.

Verify downloads against the checksum files attached to the **same release**. [Installation instructions](../docs/WINDOWS_COMPLETE_INSTALLER.md) · [Fixes and limitations](../docs/RELEASE_ALPHA58.md).

The previous Mac installer remains available under [alpha.5.7](https://github.com/Nicodemox87/ALiS/releases/tag/v0.1.0-alpha.5.7). Windows packages cannot update the Mac app.
