# Release packages

**Current Windows plugin: [alpha.5.21](https://github.com/Nicodemox87/ALiS/releases/tag/v0.1.0-alpha.5.21)**. The matching `VERSION.json` and checksums describe its Windows ZIP and source archive. See the [complete user guide](../docs/USER_GUIDE_IT.md). An existing CloudCompare 2.13.2 x64 / Qt5 is required; this ZIP is not a complete host/runtime installer.

**Next roadmap step: update macOS.** No Mac alpha.5.21 installer is included. The previous alpha.5.9 Mac package remains available separately.

## Historical packages retained below

Older binaries in this directory belong to the historical **Windows alpha.5.7** snapshot. Do not use the new checksum list to validate old files: use the checksums attached to the same release as the download.

For **Windows/macOS alpha.5.9**, including progressive features and update checks, use the [current release](https://github.com/Nicodemox87/ALiS/releases/tag/v0.1.0-alpha.5.9). The complete Windows installer prepares CloudCompare, ALiS and the Python ML/DL runtime; plugin-only setup and manual ZIP are alternatives. The native arm64 Mac installer is a separate PKG.

Verify downloads against the checksum files attached to the **same release**. [Installation instructions](../docs/WINDOWS_COMPLETE_INSTALLER.md) · [Fixes and limitations](../docs/RELEASE_ALPHA59.md).

The previous Mac installer remains available under [alpha.5.7](https://github.com/Nicodemox87/ALiS/releases/tag/v0.1.0-alpha.5.7). Windows packages cannot update the Mac app.
