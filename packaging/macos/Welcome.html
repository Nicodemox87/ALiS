ALiS per Mac Apple Silicon

Installa ALiS, CloudCompare 2.13.2, Python e tutti i classificatori, incluso PointNet. Non servono Homebrew, compilatori o download aggiuntivi per iniziare.

Richiede macOS 27 o successivo e un Mac M1, M2, M3, M4 o successivo. Questa versione è una preview sperimentale.

Salva il lavoro e chiudi ALiS prima di proseguire. L'installer gestisce esclusivamente /Applications/ALiS.app. Conserva dati, modelli, report, impostazioni e le altre installazioni di CloudCompare.

Il controllo automatico interroga le release pubbliche di Nicodemox87/ALiS su GitHub una volta al giorno. Puoi disattivarlo in ALiS Settings → Updates. Nessuna nuvola o modello viene inviato.
